AROMA Y CAFÉ — PROYECTO DE TIENDA EN LÍNEA

ARCHIVOS
- index.html: estructura de la página.
- styles.css: diseño visual y adaptación a móviles.
- script.js: catálogo, búsqueda, filtros, carrito y formularios de demostración.

CÓMO ABRIR EN VISUAL STUDIO CODE
1. Descomprime aroma_y_cafe.zip en una carpeta.
2. Abre Visual Studio Code.
3. Selecciona Archivo > Abrir carpeta y elige aroma_y_cafe.
4. Abre index.html.
5. Puedes hacer doble clic en index.html para abrirlo en el navegador. Opcionalmente instala la extensión Live Server y pulsa “Go Live”.

FUNCIONES
- Catálogo de productos con precios en MXN.
- Buscador, filtros por categoría y orden por precio.
- Carrito con cantidades y subtotal.
- Promoción de demostración HOLAAROMA.
- Formulario de compra de demostración.
- Secciones informativas sobre formas de pago, impuestos, logística, registro, empresa y costos.
- Diseño responsive para teléfono, tableta y escritorio.

IMPORTANTE
Es un prototipo escolar front-end. No procesa pagos, no crea cuentas reales, no almacena información y no envía pedidos. Antes de vender de verdad, necesitarías backend, base de datos, medidas de seguridad, aviso de privacidad, términos comerciales y una pasarela de pago contratada. Las políticas, precios, tiempos de envío y datos de contacto son ejemplos. SafetyPay y la disponibilidad de cualquier proveedor de pagos deben verificarse antes de integrar el servicio.

COSTOS
El prototipo puede abrirse localmente sin costo de licencia. Un sitio publicado puede requerir dominio, hosting/plataforma, mantenimiento, fotografía, marketing y comisiones por transacción; el costo depende del proveedor y del alcance.
